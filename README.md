# 屏幕陪练老师（Screen Guide Teacher）

这是一个面向 Windows 新手的本地辅助工具：在用户明确选择并授权一个窗口后，读取该窗口的画面和可访问控件，用中文语音或文字告诉用户下一步应该怎么操作。

## 当前阶段

项目目前已经具备可运行的 Windows 设置界面、系统托盘入口、全局快捷键、本地唤醒词、本地流式中文识别与中文语音播报。Windows 原生窗口选择器和观察权限状态基础仍保留，但尚未接入后台语音流程中的真实画面读取或 AI 回答。

第一版只做：

1. 用户主动选择一个允许查看的窗口。
2. 软件读取该窗口的当前画面与按钮文字。
3. 用户不切换当前软件，通过全局快捷键用语音提出问题。
4. AI 给出一步一条的中文指导。
5. 用户亲自点击后，软件重新观察并判断是否正确。

第一版明确不做：

- 不自动点击、输入或控制鼠标键盘。
- 不在用户不知情时截图、录音或后台监控。
- 不上传整块硬盘、浏览器 Cookie、密码或登录令牌。
- 不把截图、录音、日志或 API Key 提交到 Git。

## 隐私原则

- 代码仓库与私人数据完全分开。
- 所有屏幕读取都要由用户选择目标窗口并明确启动。
- 默认只在界面发生变化或用户要求“看一下”时分析，不持续上传视频流。
- API Key 只保存在本机用户配置中，不写入源代码。
- 涉及点击、输入、删除、支付、发布等操作时，未来版本仍需单独确认。

## 本地开发

需要 .NET 10 SDK。在项目根目录执行：

```powershell
dotnet build ScreenGuide.slnx
dotnet test ScreenGuide.slnx
dotnet run --project src/ScreenGuide.App/ScreenGuide.App.csproj
```

当前点击“开始后台陪练并隐藏”后，设置窗口会隐藏到系统托盘。用户可以停留在正在学习的软件里，直接说“你好贾维斯”；听到提示音后说出问题，程序会在本机识别文字，通过系统中文语音复述结果，并在回答结束后自动继续等待下一次唤醒。全局快捷键仍作为备用提问入口，停止快捷键、设置页停止按钮和托盘“立即停止麦克风”都能随时结束监听。

唤醒词和中文识别使用 sherpa-onnx 本地模型。模型安装在 `%LOCALAPPDATA%\ScreenGuideTeacher\models`，唤醒词配置安装在 `%LOCALAPPDATA%\ScreenGuideTeacher\config`，两者都不进入 Git 仓库。麦克风音频只以短音频块在内存中处理，当前实现不会写入录音文件，也不会上传音频。

当前尚未连接画面读取和 AI 模型，所以这一阶段只验证“不切换窗口也能语音提问和听到回答”的通路。下一阶段会在用户主动触发后读取当时的目标窗口一次，再通过可替换的模型接口生成真正的操作指导。
