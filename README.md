# 屏幕陪练老师（Screen Guide Teacher）

这是一个面向 Windows 新手的本地辅助工具：在用户明确选择并授权一个窗口后，读取该窗口的画面和可访问控件，用中文语音或文字告诉用户下一步应该怎么操作。

## 当前阶段

项目目前处于“安全骨架”阶段，尚未实现屏幕读取或鼠标控制。

第一版只做：

1. 用户主动选择一个允许查看的窗口。
2. 软件读取该窗口的当前画面与按钮文字。
3. 用户用文字或语音提出问题。
4. AI 给出一步一条的中文指导。
5. 用户亲自点击后，软件重新观察并判断是否正确。

第一版明确不做：

- 不自动点击、输入或控制鼠标键盘。
- 不在用户不知情时截图、录音或后台监控。
- 不上传整块硬盘、浏览器 Cookie、密码或登录令牌。
- 不把截图、录音、日志或 API Key 提交到 Git。

## 隐私原则

- 代码仓库与私人数据完全分开。
- 所有屏幕读取都要由用户选择目标窗口并明确启动。
- 默认只在界面发生变化或用户要求“看一下”时分析，不持续上传视频流。
- API Key 只保存在本机用户配置中，不写入源代码。
- 涉及点击、输入、删除、支付、发布等操作时，未来版本仍需单独确认。
