# 贾维斯（Jarvis）

贾维斯是一个面向 Windows 新手的本地辅助工具：在用户明确选择并授权一个窗口后，读取该窗口的画面和可访问控件，用中文语音或文字告诉用户下一步应该怎么操作。

## 当前阶段

项目目前已经具备可运行的 Windows 贾维斯悬浮形象、独立设置页、系统托盘入口、全局快捷键、本地唤醒词与本地流式中文识别。日常启动只显示可拖动的贾维斯形象；它可以缩小成右上角悬浮图标，也可以隐藏到任务栏而不影响已经启动的后台语音。程序已加入阿里百炼隐私折中链路：只有用户选择一个窗口并再次勾选云端授权后，每次提问才读取该窗口的一帧画面，并把这一帧和识别文字发送给千问；回答文字通过 CosyVoice 流式朗读。

第一版只做：

1. 用户主动选择一个允许查看的窗口。
2. 软件读取该窗口的当前画面与按钮文字。
3. 用户不切换当前软件，通过全局快捷键用语音提出问题。
4. AI 给出一步一条的中文指导。
5. 用户亲自点击后，软件重新观察并判断是否正确。

第一版明确不做：

- 不自动点击、输入或控制鼠标键盘。
- 不在用户不知情时截图、录音或后台监控。
- 不上传整块硬盘、浏览器 Cookie、密码或登录令牌。
- 不把截图、录音、日志或 API Key 提交到 Git。

## 隐私原则

- 代码仓库与私人数据完全分开。
- 所有屏幕读取都要由用户选择目标窗口并明确启动。
- 默认只在界面发生变化或用户要求“看一下”时分析，不持续上传视频流。
- API Key 只保存在 Windows 凭据管理器中；普通模型配置保存在 `%LOCALAPPDATA%\ScreenGuideTeacher\config`，都不写入源代码。
- 涉及点击、输入、删除、支付、发布等操作时，未来版本仍需单独确认。

## 本地开发

需要 .NET 10 SDK。在项目根目录执行：

```powershell
dotnet build ScreenGuide.slnx
dotnet test ScreenGuide.slnx
dotnet run --project src/ScreenGuide.App/ScreenGuide.App.csproj
```

双击桌面图标后会先出现贾维斯悬浮形象，而不是配置面板。右键贾维斯可启动语音、打开设置、缩小、隐藏或退出；双击角色可在大形态和悬浮图标之间切换。首次使用时，在设置页保存并测试华北2（北京）地域的百炼 API Key，选择要学习的软件窗口，再勾选单帧云端授权。启动语音后，用户可以停留在正在学习的软件里，直接说“你好贾维斯”；听到提示音后说出问题，程序会在本机识别文字，按需读取授权窗口的一帧，由千问流式生成回答，并由 CosyVoice 边生成边朗读。隐藏外形不会停止语音；停止快捷键、设置页按钮、悬浮形象右键菜单和托盘菜单都能随时结束监听。

长回答不会再在 15 秒或 30 秒处被截断：云端语音会一直播放到缓冲区真正结束。只有整轮处理连续超过 5 分钟，或播放设备连续 10 秒没有任何进度时，程序才会取消本轮并自动恢复唤醒词监听；悬浮形象的状态文字、光环和右下角状态灯会显示“待命、正在听、正在处理、回答或已停止”。

唤醒词由 Windows 中文语音识别、sherpa-onnx 专用唤醒模型和 sherpa-onnx 中文流式识别三条本地通道共同判断，并在检测到麦克风声音时显示明确反馈。Sherpa 模型安装在 `%LOCALAPPDATA%\ScreenGuideTeacher\models`，唤醒词配置安装在 `%LOCALAPPDATA%\ScreenGuideTeacher\config`，两者都不进入 Git 仓库。麦克风音频只以短音频块在内存中处理，当前实现不会写入录音文件，也不会上传音频。

云端链路使用可替换的模型接口，默认视觉模型为 `qwen3-vl-flash`，默认语音模型为 `qwen-audio-3.0-tts-flash`。没有 API Key、没有准确选择窗口或没有勾选上传授权时，程序会阻止云端陪练启动；“我现在在哪个界面”仍可用本机窗口标题快速回答。当前尚未加入自动点击、键盘输入或鼠标控制。

当前有一个不联网的快速回答：用户询问“我现在在哪个界面”时，程序会读取唤醒瞬间的前台窗口标题并直接播报。除此之外，在真正的 AI 服务接通前，程序会明确说明尚未接通，不再用固定话术假装已经完成智能分析。
