# 贾维斯（Jarvis）

贾维斯是一个面向 Windows 新手的后台语音助手：用户可以停留在任何软件里随时唤醒提问。普通问题不读取屏幕；只有用户主动询问当前界面、按钮或报错并为本次运行明确授权后，才读取当时前台软件的一帧，用中文语音告诉用户下一步。

## 当前阶段

项目目前已经具备可运行的 Windows 贾维斯实时粒子悬浮形象、故障排查设置页、系统托盘入口、全局快捷键、本地唤醒词与本地流式中文识别。悬浮形象入场时临时使用全屏透明、鼠标穿透的动画层，让粒子从屏幕四周之外飞入；聚合后，深红与枪灰黑的半实体金属底板在粒子下方渐显，随后窗口自动缩回普通大小。正常双击桌面图标后会请求一次“本次运行的当前窗口单帧授权”，随后自动进入后台待命，不需要打开设置页，也不需要绑定固定软件。用户切换到另一个软件后，下次唤醒提问会自动跟随新的前台窗口。普通问题只把识别文字发送给关闭思考模式的 `deepseek-v4-flash`；明确需要看屏幕的问题才读取当时前台软件的一帧并发送给 `qwen3.7-plus`。回答文字通过百炼语音流式朗读。

第一版只做：

1. 用户启动时明确决定是否允许本次运行按需查看当前前台窗口。
2. 软件只在屏幕问题发生时读取当时前台窗口的一帧与按钮文字。
3. 用户可以在任意软件里通过唤醒词或全局快捷键提出问题。
4. AI 给出一步一条的中文指导。
5. 用户亲自点击后，软件重新观察并判断是否正确。

第一版明确不做：

- 不自动点击、输入或控制鼠标键盘。
- 不在用户不知情时截图、录音或后台监控。
- 不上传整块硬盘、浏览器 Cookie、密码或登录令牌。
- 不把截图、录音、日志或 API Key 提交到 Git。

## 隐私原则

- 代码仓库与私人数据完全分开。
- 所有屏幕读取都要先取得本次运行的明确授权，并且只能读取提问时的单个前台窗口。
- 默认只在界面发生变化或用户要求“看一下”时分析，不持续上传视频流。
- API Key 只保存在 Windows 凭据管理器中；普通模型配置保存在 `%LOCALAPPDATA%\ScreenGuideTeacher\config`，都不写入源代码。
- 涉及点击、输入、删除、支付、发布等操作时，未来版本仍需单独确认。

## 本地开发

需要 .NET 10 SDK。在项目根目录执行：

```powershell
dotnet build ScreenGuide.slnx
dotnet test ScreenGuide.slnx
dotnet run --project src/ScreenGuide.App/ScreenGuide.App.csproj
```

首次使用时，在设置页保存并测试华北2（北京）地域的百炼 API Key。之后双击桌面图标，确认或拒绝“本次运行的当前窗口单帧授权”，贾维斯便会自动进入后台语音待命。用户在任何软件里说一次“你好贾维斯”并提出第一个问题后会进入连续对话；每次回答完成都会自动继续听下一句话，不必重复唤醒。单独说“你退下吧”“退下”“退出对话”或“退出”会无声结束连续对话并回到唤醒词待命。切换软件后无需重新配置。

长回答不会再在 15 秒或 30 秒处被截断：云端语音会一直播放到缓冲区真正结束。只有整轮处理连续超过 5 分钟，或播放设备连续 10 秒没有任何进度时，程序才会取消本轮并自动恢复唤醒词监听；悬浮形象会通过粒子亮度、颜色、眼部脉冲和短暂状态文字显示“待命、正在听、正在处理、回答或已停止”。

唤醒词由 Windows 中文语音识别、sherpa-onnx 专用唤醒模型和 sherpa-onnx 中文流式识别三条本地通道共同判断，并在检测到麦克风声音时显示明确反馈。Sherpa 模型安装在 `%LOCALAPPDATA%\ScreenGuideTeacher\models`，唤醒词配置安装在 `%LOCALAPPDATA%\ScreenGuideTeacher\config`，两者都不进入 Git 仓库。麦克风音频只以短音频块在内存中处理，当前实现不会写入录音文件，也不会上传音频。

云端链路使用可替换的模型接口，默认文字模型为 `deepseek-v4-flash`（关闭思考模式），默认视觉模型为 `qwen3.7-plus`，默认语音模型为 `qwen-audio-3.0-tts-flash`。没有 API Key 时程序会打开设置页；未同意本次运行的屏幕授权时普通文字问答仍可使用，但屏幕问题不会读取画面。“我现在在哪个界面”“这是什么网站”等问法会读取授权窗口的一帧并交给视觉模型，不再只凭窗口标题猜测。当前尚未加入自动点击、键盘输入或鼠标控制。

多轮对话历史只保存在本次程序运行的内存中，退出即清空，不写入硬盘。普通问题与屏幕问题都使用约 90 万 Token 历史预算，并为系统指令、当前问题、图像和回答预留空间。历史越长，每轮输入计费和首字延迟通常越高。

界面识别会优先核对浏览器域名、网站标志、页面主标题和关键表单文字，至少两项证据吻合后再下结论。程序不再使用 Windows 本地声音播报窗口标题，因此正常问答与屏幕问答会使用同一套云端音色；只有云端语音故障时才会临时回退到 Windows 中文声音。
