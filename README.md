# 贾维斯（Jarvis）

贾维斯是一个面向 Windows 新手的后台语音助手：用户可以停留在任何软件里随时唤醒提问。普通问题不读取屏幕；只有用户主动询问当前界面、按钮或报错并为本次运行明确授权后，才读取当时前台软件的一帧，用中文语音告诉用户下一步。

## 当前阶段

项目目前已经具备可运行的 Windows 贾维斯实时粒子悬浮形象、故障排查设置页、系统托盘入口、全局快捷键、本地唤醒词与本地流式中文识别。正常双击桌面图标后会请求一次“本次运行的当前窗口单帧授权”，随后自动进入后台待命，不需要打开设置页，也不需要绑定固定软件。用户切换到另一个软件后，下次唤醒提问会自动跟随新的前台窗口。普通问题只把识别文字发送给关闭思考模式的 `deepseek-v4-flash`；明确需要看屏幕的问题才读取当时前台软件的一帧并发送给 `qwen3-vl-flash`。回答文字通过百炼语音流式朗读。

第一版只做：

1. 用户启动时明确决定是否允许本次运行按需查看当前前台窗口。
2. 软件只在屏幕问题发生时读取当时前台窗口的一帧与按钮文字。
3. 用户可以在任意软件里通过唤醒词或全局快捷键提出问题。
4. AI 给出一步一条的中文指导。
5. 用户亲自点击后，软件重新观察并判断是否正确。

第一版明确不做：

- 不自动点击、输入或控制鼠标键盘。
- 不在用户不知情时截图、录音或后台监控。
- 不上传整块硬盘、浏览器 Cookie、密码或登录令牌。
- 不把截图、录音、日志或 API Key 提交到 Git。

## 隐私原则

- 代码仓库与私人数据完全分开。
- 所有屏幕读取都要先取得本次运行的明确授权，并且只能读取提问时的单个前台窗口。
- 默认只在界面发生变化或用户要求“看一下”时分析，不持续上传视频流。
- API Key 只保存在 Windows 凭据管理器中；普通模型配置保存在 `%LOCALAPPDATA%\ScreenGuideTeacher\config`，都不写入源代码。
- 涉及点击、输入、删除、支付、发布等操作时，未来版本仍需单独确认。

## 本地开发

需要 .NET 10 SDK。在项目根目录执行：

```powershell
dotnet build ScreenGuide.slnx
dotnet test ScreenGuide.slnx
dotnet run --project src/ScreenGuide.App/ScreenGuide.App.csproj
```

首次使用时，在设置页保存并测试华北2（北京）地域的百炼 API Key。之后双击桌面图标，确认或拒绝“本次运行的当前窗口单帧授权”，贾维斯便会自动进入后台语音待命。用户可以停留在任何软件里说“你好贾维斯”并提问；切换软件后无需重新配置。程序在本机识别文字，自动选择 DeepSeek 文字回答或千问单帧视觉回答，并由百炼语音边生成边朗读。设置页只用于更换密钥、查看耗时和故障排查；停止快捷键、悬浮形象右键菜单和托盘菜单都能随时结束监听。

长回答不会再在 15 秒或 30 秒处被截断：云端语音会一直播放到缓冲区真正结束。只有整轮处理连续超过 5 分钟，或播放设备连续 10 秒没有任何进度时，程序才会取消本轮并自动恢复唤醒词监听；悬浮形象会通过粒子亮度、颜色、眼部脉冲和短暂状态文字显示“待命、正在听、正在处理、回答或已停止”。

唤醒词由 Windows 中文语音识别、sherpa-onnx 专用唤醒模型和 sherpa-onnx 中文流式识别三条本地通道共同判断，并在检测到麦克风声音时显示明确反馈。Sherpa 模型安装在 `%LOCALAPPDATA%\ScreenGuideTeacher\models`，唤醒词配置安装在 `%LOCALAPPDATA%\ScreenGuideTeacher\config`，两者都不进入 Git 仓库。麦克风音频只以短音频块在内存中处理，当前实现不会写入录音文件，也不会上传音频。

云端链路使用可替换的模型接口，默认文字模型为 `deepseek-v4-flash`（关闭思考模式），默认视觉模型为 `qwen3-vl-flash`，默认语音模型为 `qwen-audio-3.0-tts-flash`。没有 API Key 时程序会打开设置页；未同意本次运行的屏幕授权时普通文字问答仍可使用，但屏幕问题不会读取画面。“我现在在哪个界面”仍可用本机窗口标题快速回答。当前尚未加入自动点击、键盘输入或鼠标控制。

多轮对话历史只保存在本次程序运行的内存中，退出即清空，不写入硬盘。普通问题会在 DeepSeek 的 100 万 Token 上限内使用约 90 万 Token 历史预算；屏幕问题按千问视觉的 262,144 Token 上限使用约 22 万 Token 历史预算，均为系统指令、当前问题、图像和回答预留空间。历史越长，每轮输入计费和首字延迟通常越高。

当前有一个不联网的快速回答：用户询问“我现在在哪个界面”时，程序会读取唤醒瞬间的前台窗口标题并直接播报。除此之外，在真正的 AI 服务接通前，程序会明确说明尚未接通，不再用固定话术假装已经完成智能分析。
