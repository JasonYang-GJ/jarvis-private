# 隐私与安全约定

## 本地语音唤醒

- 用户主动双击桌面图标后，程序会自动打开麦克风并在本机等待“你好贾维斯”；用户可在授权提示中单独拒绝屏幕读取，也可随时从托盘、悬浮形象或快捷键停止麦克风。
- 唤醒与问题识别都由本机 sherpa-onnx 模型完成；当前版本不把麦克风音频发送到网络。
- 音频只以短音频块存在于内存中，不生成录音文件。模型和唤醒词配置保存在当前用户的 `%LOCALAPPDATA%\ScreenGuideTeacher` 下，不进入源码仓库。
- 用户可通过设置页停止按钮、全局停止快捷键或系统托盘“立即停止麦克风”结束监听。停止流程会关闭麦克风并释放本地模型。
- 当前版本不注册隐藏启动项，也不会在程序完全退出后继续监听。未来若加入开机启动，必须由用户单独、明确开启，并保持可见的托盘状态和关闭入口。

## 默认策略

- 程序启动后不会自动截图；只有识别到屏幕问题时才可能捕获。
- 正常启动时必须明确确认或拒绝“本次运行的当前前台窗口单帧授权”，授权不会跨越程序重启自动延续。
- 捕获期间持续显示明显状态，提供始终可见的“停止观察”。
- 第一版只观察，不执行点击、输入或系统操作。
- 仅在用户提问或检测到需要核验时抓取单帧，不默认传输连续视频。
- 截图优先保存在内存，处理完成后释放。

## 阿里百炼隐私折中模式

- 麦克风音频由本机 sherpa-onnx 识别，不发送给阿里百炼。
- 普通问题只发送识别后的文字，不读取屏幕。只有问题明确涉及当前页面、按钮、报错或画面时，才进入视觉路线。
- 视觉路线要求用户先为本次运行明确授权。每次唤醒时，用户当前聚焦的软件被视为本次问题的目标；切换软件后，下次提问自动跟随。
- 每次视觉问题只读取当时前台软件的一帧，不采集整个桌面，不上传连续视频，也不把截图写入硬盘。若前台是贾维斯自身或无法准确定位，则拒绝读取。
- 普通问题发送给百炼的数据只有识别后的问题文字；视觉问题额外包含当前窗口标题和当次内存截图。回答文字会发送给百炼语音合成服务；不会发送麦克风录音。
- API Key 保存到 Windows 凭据管理器；模型名和 API Host 保存到 `%LOCALAPPDATA%\ScreenGuideTeacher\config\bailian.json`。
- 取消勾选、停止后台陪练或退出程序后，不再产生新的画面请求；程序重新启动时必须重新授权。

## 永不进入公开仓库的数据

- API Key、访问令牌、Cookie、密码和授权文件。
- 真实截图、屏幕录像和麦克风录音。
- 含用户名、完整本机路径或个人文件名的日志。
- 用户问题历史、AI 对话记录和操作轨迹。
- 本地数据库和个性化配置。

## 正式公开前检查

1. 检查 Git 全部历史，而不只是当前文件。
2. 执行密钥扫描和依赖许可证检查。
3. 用全新的 Windows 测试账户完成一次安装和卸载测试。
4. 验证关闭捕获后不再产生画面。
5. 确认 README 准确说明本地与云端处理边界。
6. 由项目所有者明确选择开源许可证。
