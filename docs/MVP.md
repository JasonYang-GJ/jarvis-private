# 第一版范围与验收标准

## 目标用户

看不懂英文软件或复杂电脑界面，希望有人像老师一样一步一步指导的 Windows 用户。

## 一次完整流程

1. 用户启动软件。
2. 点击“选择要学习的软件”。
3. Windows 弹出安全选择界面，用户选择 GitHub Desktop。
4. 软件显示“正在观察：GitHub Desktop”。
5. 用户说或输入：“我现在在哪个界面？”
6. 软件读取当前窗口及可访问控件，回答界面名称和用途。
7. 软件只给出一个下一步，例如“请点击左上角 History”。
8. 用户亲自点击。
9. 软件按需重新读取窗口，回答“操作正确”或给出纠正方法。
10. 用户点击“停止观察”，读取立即结束。

## 必须通过的验收

- 未选择窗口时，软件无法读取屏幕。
- 只能读取用户选择的窗口。
- 界面持续显示当前正在观察的窗口名称。
- 点击“停止观察”后不再获得新画面。
- 第一版没有鼠标、键盘自动控制能力。
- 没有 API Key 时可以进入演示模式，不会崩溃。
- 提交到 Git 的内容不包含截图、录音、日志或密钥。

## 当前实现进度

- [x] 打开 Windows 原生安全选择界面。
- [x] 用户取消时不产生新授权，并保留原有安全状态。
- [x] 选择目标后显示窗口名称和尺寸。
- [x] 点击“停止观察”或目标关闭后清除授权状态。
- [ ] 按需读取被授权窗口的一张测试画面。
- [ ] 读取被授权窗口的可访问按钮和文字。
- [ ] 根据用户问题生成一步一条的中文指导。

当前完成的是“选择和授权”，并不等于已经读取屏幕。真正的画面捕获必须在下一阶段另外创建捕获会话后才会发生。

## 暂缓功能

- 自动点击和自动输入。
- 整个桌面持续监控。
- 无人值守远程控制。
- 支付、发布、删除文件等高风险操作。
- 手机远程连接。
