# 第一版范围与验收标准

## 目标用户

看不懂英文软件或复杂电脑界面，希望有人像老师一样一步一步指导的 Windows 用户。

## 一次完整流程

1. 用户启动软件。
2. 首次使用时用户保存并测试自己的百炼 API Key；以后正常启动只需确认或拒绝本次运行的当前窗口单帧授权。
3. 程序自动进入后台语音待命，用户可以停留在 GitHub Desktop、浏览器或其他软件。
4. 用户说“你好贾维斯”或使用备用全局语音快捷键，直接提出问题。
5. 程序在本机只识别唤醒后的这一句话，并用不抢焦点的小浮层显示状态。
6. 普通问题不截屏；屏幕问题在已授权时按需读取提问时的前台窗口，回答界面名称和用途。
7. 程序通过中文语音只给出一个下一步，例如“请点击左上角 History”。
8. 用户亲自点击，全程不切换到陪练设置窗口。
9. 用户再次按语音快捷键进行核对。
10. 用户按停止快捷键，监听与读取立即结束。

## 必须通过的验收

- 未明确授权本次运行时，软件无法读取屏幕。
- 每次只能读取用户当时正在使用的一个前台窗口，不能读取整个桌面。
- 后台状态浮层不抢走当前软件的键盘焦点。
- 程序进入后台待命后只在本机监听唤醒词；退出或停止后不监听麦克风。
- 点击“停止观察”后不再获得新画面。
- 第一版没有鼠标、键盘自动控制能力。
- 没有 API Key 或本次运行的额外云端授权时，不会读取或上传画面，并会明确提示缺少的设置。
- 提交到 Git 的内容不包含截图、录音、日志或密钥。

## 暂缓功能

- 自动点击和自动输入。
- 整个桌面持续监控。
- 无人值守远程控制。
- 支付、发布、删除文件等高风险操作。
- 手机远程连接。
