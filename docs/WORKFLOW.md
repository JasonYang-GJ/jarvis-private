# 屏幕陪练老师完整工作流程

```mermaid
flowchart TD
    A[双击桌面上的“屏幕陪练老师”] --> B[打开设置窗口]
    B --> C{百炼 API Key 是否已保存}
    C -- 否 --> C1[用户填写 Key]
    C1 --> C2[保存到 Windows 凭据管理器]
    C2 --> D
    C -- 是 --> D[用户选择允许观察的软件窗口]
    D --> E[Windows 返回目标窗口授权]
    E --> F{用户是否勾选单帧云端授权}
    F -- 否 --> F1[阻止启动云端画面问答]
    F1 --> F
    F -- 是 --> G[点击“开始后台陪练并隐藏”]

    G --> H[加载本地语音模型]
    H --> I[启动三条本地唤醒通道]
    I --> I1[Windows 中文语音识别]
    I --> I2[Sherpa 专用唤醒模型]
    I --> I3[Sherpa 中文连续识别备份]
    I1 --> J[等待“你好贾维斯”]
    I2 --> J
    I3 --> J

    J --> K{是否听到声音}
    K -- 否 --> J
    K -- 是 --> K1[右上角显示“麦克风已经听到声音”]
    K1 --> L{是否匹配唤醒词}
    L -- 否 --> J
    L -- 是 --> M[提示音并显示“我在，请说”]
    M --> N[本机识别一句中文问题]

    N --> O{是否为“我在哪个界面”}
    O -- 是 --> O1[本机读取前台窗口标题]
    O1 --> T[本机语音直接回答]
    O -- 否 --> P[读取已授权窗口的一帧画面]
    P --> P1[画面只放在内存中，不写入硬盘]
    P1 --> Q[问题文字和单帧画面发送给百炼千问]
    Q --> R[千问流式生成简短指导文字]
    R --> S[文字片段发送给百炼语音合成]
    S --> S1[收到 PCM 音频后边接收边播放]
    S1 --> S2[云端结束后继续播放剩余缓冲区]
    S2 --> T[回答播放完整]

    T --> U[自动恢复等待“你好贾维斯”]
    U --> J

    N -. 识别失败 .-> V[显示原因并恢复待命]
    P -. 窗口失效 .-> V
    Q -. 网络或模型失败 .-> V
    S -. 语音失败 .-> W[改用 Windows 中文声音]
    W --> U
    S2 -. 播放设备10秒无进度 .-> V
    G -. 用户点击停止或停止快捷键 .-> X[立即关闭麦克风并撤销本轮]
    X --> Y[右上角持续显示“已停止”]
```

## 数据是否离开电脑

- 始终留在本机：唤醒词音频、问题语音、API Key、目标窗口授权状态。
- 用户每次提问后才发送：识别后的问题文字、已授权窗口的一帧画面。
- 云端返回：指导文字与合成后的回答音频。
- 不会进入 GitHub：API Key、真实截图、录音和个人运行数据。

## 当前能力边界

- 软件只观察并告诉用户下一步，不替用户点击、输入或移动鼠标。
- 每次只读取用户明确选择的一个窗口，不读取整个桌面。
- 目前一次唤醒识别一句问题；回答完成后再次说“你好贾维斯”进入下一轮。
