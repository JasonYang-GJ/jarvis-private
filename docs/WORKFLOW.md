# 贾维斯完整工作流程

```mermaid
flowchart TD
    A[双击桌面上的“贾维斯”] --> A1[粒子从四周聚合成贾维斯头盔]
    A1 --> A2{百炼和本地语音是否已配置}
    A2 -- 否 --> B[打开设置与故障排查]
    A2 -- 是 --> C{是否允许本次运行按需读取当前窗口一帧}
    C -- 允许 --> C1[开启本次运行屏幕授权]
    C -- 拒绝 --> C2[保持纯文字语音问答]
    C1 --> G[自动进入后台语音待命]
    C2 --> G
    A1 -. 外形操作 .-> A3[双击缩小为右上角粒子图标]
    A1 -. 外形操作 .-> A4[隐藏到任务栏，后台语音保持运行]
    A1 -. 故障排查 .-> B

    G --> H[加载本地语音模型]
    H --> I[启动三条本地唤醒通道]
    I --> I1[Windows 中文语音识别]
    I --> I2[Sherpa 专用唤醒模型]
    I --> I3[Sherpa 中文连续识别备份]
    I1 --> J[等待“你好贾维斯”]
    I2 --> J
    I3 --> J

    J --> K{是否听到声音}
    K -- 否 --> J
    K -- 是 --> K1[贾维斯光环显示“麦克风已经听到声音”]
    K1 --> L{是否匹配唤醒词}
    L -- 否 --> J
    L -- 是 --> M[无提示音，显示“我在，请说”]
    M --> M1[记住当前外部前台窗口]
    M1 --> N[本机识别一句中文问题]

    N --> N0{是否为退下或退出口令}
    N0 -- 是 --> J
    N0 -- 否 --> O{是否为“我在哪个界面”}
    O -- 是 --> O1[本机读取前台窗口标题]
    O1 --> T[本机语音直接回答]
    O -- 否 --> O2{问题是否需要看屏幕}
    O2 -- 否 --> O3[只把问题文字交给 DeepSeek]
    O2 -- 是且已授权 --> P[读取当前前台窗口的一帧画面]
    O2 -- 是但未授权 --> V
    P --> P1[画面只放在内存中，不写入硬盘]
    P1 --> Q[问题文字和单帧画面发送给百炼千问]
    Q --> R[千问流式生成简短指导文字]
    O3 --> R
    R --> S[文字片段发送给百炼语音合成]
    S --> S1[收到 PCM 音频后边接收边播放]
    S1 --> S2[云端结束后继续播放剩余缓冲区]
    S2 --> T[回答播放完整]

    T --> U[自动继续听下一句话]
    U --> M1

    N -. 识别失败 .-> V[显示原因并恢复待命]
    P -. 窗口失效 .-> V
    Q -. 网络或模型失败 .-> V
    S -. 语音失败 .-> W[改用 Windows 中文声音]
    W --> U
    S2 -. 播放设备10秒无进度 .-> V
    G -. 用户点击停止或停止快捷键 .-> X[立即关闭麦克风并撤销本轮]
    X --> Y[贾维斯状态灯持续显示“已停止”]
```

## 数据是否离开电脑

- 始终留在本机：唤醒词音频、问题语音、API Key、本次运行的屏幕授权状态。
- 普通问题只发送识别后的文字；屏幕问题在已授权时额外发送当前前台窗口的一帧。
- 云端返回：指导文字与合成后的回答音频。
- 不会进入 GitHub：API Key、真实截图、录音和个人运行数据。

## 当前能力边界

- 软件只观察并告诉用户下一步，不替用户点击、输入或移动鼠标。
- 每次只读取用户提问时正在使用的一个前台窗口，不读取整个桌面；切换软件后下次提问自动跟随。
- 目前一次唤醒识别一句问题；回答完成后再次说“你好贾维斯”进入下一轮。
