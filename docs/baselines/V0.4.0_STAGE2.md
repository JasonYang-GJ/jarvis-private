## 2. 正式能力边界

- 普通聊天业务仅依赖 `IChatModelProvider`，Provider 由 Registry/Router 解析并在 Turn 开始时冻结。
- 发布目标为 DeepSeek + Qwen；Qwen `qwen3.7-plus` 是用户手动备用，不会自动 fallback、retry 或跨 Provider resend。
- Codex 普通聊天适配器保持 `ProductionDisabled`/`PolicyDisabled`；编程 Task 继续由独立 Codex Connector/Skill 执行。
- Prompt Registry、DPAPI CurrentUser 凭据、短生命期 lease、AI Invocation 审计、稳定错误和无敏感数据证据纳入发布合同。
- 模型语义输出只是不可信建议；项目、文件、窗口、动作和确认权限仍由本机确定性 Planner/CapabilityPolicy 决定。
- 长期记忆、RAG、向量数据库、用户画像、手机端、云远控、复杂多 Agent 产品和开放式 Tool Calling 不属于本基线。
