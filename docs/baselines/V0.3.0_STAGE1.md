## 3. 本版本正式能力范围

- 唯一 SessionCoordinator 统一普通聊天、受控电脑动作、单窗口观察和编程任务的 Session / Turn 状态。
- 首页输入默认继续当前 Session 和同一 Conversation / Provider Thread；显式“新话题”创建新 Session。
- 应用/Host 重启恢复当前 Session；运行中的不安全工作中断且不自动重放。
- 用户停止或新输入真正取消 Provider / Codex 进程树、窗口观察或真实编程 Task。
- Conversation 取消与成功提交争夺 SQLite 唯一终态；每 Turn 的确认、授权和取消串行处理。已取消 Turn 拒绝迟到 Assistant 消息与迟到成功，不能覆盖新回答。
- 缺项目、文件、窗口或窗口同意时，保存原始请求并在同一 Turn 补齐后继续。
- 项目只能来自现有授权，已撤权的 Session 项目会清除并重新等待；文件必须存在且仍需本次确认；窗口同意绑定本 Turn 显示的窗口句柄、进程名和标题。
- 编程任务与普通聊天共享 Session，但使用独立 Turn；后台编程任务不阻止用户继续聊天。
- 电脑操作页的已发现应用/网站入口同样创建 Session Turn；应用绑定已发现的 Application ID，网站绑定规范化完整 HTTPS URI。Host 在初次规划和确认执行两处精确比较 Expected Intent/Target 与 Canonical Plan Target，不匹配则结束 Turn 且不执行。
- UI 统一显示理解、回答、执行、等待上下文、取消、完成、失败和中断状态。
- protocol v7 的 `sessions.wait` 长轮询提供增量 Session 更新；Coordinator 实例 ID、启动时间与版本区分 Host 重启前后的新旧快照。Named Pipe 服务有连接上限、忙碌响应、首请求超时、监听重试和坏请求帧隔离。
- SQLite schema v7 持久化 Session / Turn 及 Expected/Plan Target，并在从 v5 或中间 v6 迁移前自动备份数据库。
- V0.2.1 的确定性意图、权限白名单、已授权项目、文件确认、单窗口同意和敏感动作禁令不变。

## 4. 明确不包含

- DeepSeek 接入或 DeepSeek 模型路由。
- 更换普通聊天模型或第二个可用的通用聊天 Provider。
- 用户长期记忆、RAG、向量数据库、跨 Session 个性化检索。
- 复杂多 Agent 产品功能、手机端、云同步或远程控制。
- 开放式模型 Tool Calling 或扩大 V0.2.1 动作白名单。
- Prompt 集中注册、版本化和完整评测体系；这些属于后续阶段。

- 环境：实际 Release DesktopClient + DesktopHost + 真实 Codex。

## 7. 数据兼容与迁移

- V0.3.0 首次打开 schema v5 数据库时，会先在同目录创建 `tasking.pre-v7-from-v5-<时间>.backup.db`，再迁移到 schema v7；若从开发中间态 schema v6 升级，则生成 `tasking.pre-v7-from-v6-<时间>.backup.db`。
- V0.3.0 保留原有 Conversation、Task、授权、审计和 Evidence 数据，并新增 Session / Turn 表。
- schema v7 为 Session Turn 新增 Expected Intent/Target 与 Plan Target，并有 v6 → v7 迁移和备份测试。
- V0.2.1 会拒绝 schema v7；因此“程序可以回滚”不代表“旧程序可以直接打开新数据库”。

## 8. 回滚到 V0.2.1

回滚必须保留当前 V0.3.0 源码、产物和用户数据库，不能使用 `git reset --hard`、`git clean` 或直接覆盖现有数据库。

1. 源码回滚：在新的干净目录或 Git worktree 中检出 `v0.2.1-baseline`；不要改变当前阶段 1 工作区。
2. 程序回滚：使用 V0.2.1 基线文档记录的安装包和 SHA-256，先在隔离测试环境确认。
3. 数据回滚：停止 Client/Host，完整备份当前 V0.3.0 用户数据；把自动生成的 pre-v7 数据库备份复制到独立数据目录后验证。不要让 V0.2.1 打开 schema v7 正式数据库。
4. 验收回滚：验证 Host 启动、数据库版本、原项目授权、历史任务和低风险动作，再决定是否切换正式安装。

V0.2.1 的精确源码、测试与安装包记录见 [V0.2.1_BASELINE.md](V0.2.1_BASELINE.md)。
