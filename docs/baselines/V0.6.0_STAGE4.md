## 协议、数据库与回滚

- Desktop IPC：protocol v11。
- SQLite：schema v11。
- V0.5.0 只支持 schema v10，不能直接打开 schema v11。
- 回滚到 V0.5.0 时，DesktopHost 与 DesktopClient 必须作为匹配的一对同时回滚；不得混用 v10/v11 Host 与 Client。
- 回滚必须保留 v11 主库，不得覆盖、替换或原地降级。
- 只允许在隔离数据目录使用与 schema 来源匹配的 `pre-v11-from-v10`；没有匹配备份时必须失败关闭。
- 若要继续回滚到 Stage 2/Stage 1，仍必须分别遵守 pre-v10/pre-v8 等历史边界，不能用当前源码冒充历史冻结版本。

## 发布边界

- 本机同 AppId 安装—卸载—重装生命周期尚未在隔离干净环境放行。
- 安装包尚未获得数字签名。
- 语音模型许可、下载与分发方案尚未放行。
- 因此 C0 候选不得声称可对外分发，也不得作为最终冻结安装包。
- C0 不包含真实 Provider 请求、凭据读取、GUI/麦克风验收或历史真实证据重跑。
