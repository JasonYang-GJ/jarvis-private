## 2. 正式能力边界

- 用户显式新增、查看、修正、启停和确认删除本机长期记忆；标题和正文使用 Windows DPAPI CurrentUser 专用边界保护后进入 SQLite。
- 本地相关记忆预览只由用户点击触发，使用确定性有界词法匹配，不保存查询或搜索索引，不调用模型。
- 普通聊天默认选择 0 条记忆。只有用户为单个 Turn 选择记忆、查看完整 Provider/Model/HTTPS origin/项目/标题/正文并单次确认后，才可向该 Turn 已冻结 Provider 最多发送一次。
- `chat.general@2` 把临时记忆 JSON 明确标记为不可信参考数据；`intent.semantic`、电脑动作、项目/文件/窗口授权和 Codex 编程任务永不接收记忆。
- 不自动提取、后台检索、自动注入、retry、fallback 或 resend；不包含 RAG、Embedding、向量数据库、画像、云同步或跨 Session 自动个性化。
