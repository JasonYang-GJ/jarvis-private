# 架构说明

## 建议技术路线

- 桌面应用：C# / .NET 8，Windows 原生界面。
- 画面读取：Windows Graphics Capture，由用户通过系统界面选择窗口。
- 控件识别：Windows UI Automation，优先读取按钮、菜单和文字结构。
- 语音输入输出：做成可替换模块；第一轮可以先用文字完成闭环。
- AI 分析：模型供应商适配层，本地只保存用户自己的配置。

## 组件边界

1. `WindowConsent`：负责选择窗口、展示授权状态和停止读取。
2. `Capture`：只产生被授权窗口的画面，不负责联网。
3. `UiInspection`：读取可访问控件树，不执行控件动作。
4. `Guidance`：组合画面、控件和用户问题，生成一步一条的指导。
5. `ModelProvider`：封装不同模型接口，应用核心不保存供应商密钥。
6. `LocalStorage`：保存用户设置；截图默认只存在内存，非必要不落盘。
7. `DesktopUi`：显示正在观察的窗口、指导内容和醒目的停止按钮。

## 数据流

用户选择窗口 → 取得系统授权 → 按需抓取一帧 → 读取控件文字 → 脱敏与裁剪 → AI 生成下一步 → 中文显示/朗读 → 用户亲自操作 → 再次按需检查。

## 开源边界

公开仓库只包含程序和示例。用户配置、模型密钥、真实画面、录音、操作记录和崩溃日志保存在仓库外，并默认不上传任何遥测。
